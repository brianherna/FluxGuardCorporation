# RECURSOS DEL EQUIPO

## Carpeta principal
`src/main/resources/static/assets/`

## Aquí pueden agregar
- imágenes
- logos
- iconos
- fotografías
- fondos
- SVG
- WebP/JPG/PNG

## Importante
No borren ni reubiquen:
- `src/main/resources/static/index.html`
- `src/main/resources/static/css/`
- `src/main/resources/static/js/`

Si únicamente les corresponde aportar recursos, trabajen dentro de `assets/`.
